# Contribute

Wir möchten den Benutzern dieses Paketes möglichst viele und konkrete Einstiegsszenarien in Form von examples anbieten.

We are looking for your software specifications for the HTTP Message Signing.
So please submit us your specs so we will try to make a named example which will be shipped with the Filefabrik/RFC9421
package.
Dies ermöglicht EntwicklerInnen sich schneller und unkomplizierter zu deinem Service zu verbinden.
